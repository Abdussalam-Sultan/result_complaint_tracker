--------------------------------------------------------------------------------
2. WORKFLOW WALKTHROUGH
--------------------------------------------------------------------------------

A. Admin setup
  1. Sign in as admin@oauife.edu.ng.
  2. Open Departments to assign one registered part advisor to each department.
  3. Open Course Catalog to create a course or assign an existing course to one
     or more departments. Select All Departments to share it faculty-wide.
  4. Open Staff & Students to inspect account departments and staff IDs.

B. Student registration and dashboard
  1. Open /register and select a department.
  2. Submit the form; department and shared courses are assigned automatically.
  3. Sign in as a student. The dashboard lists registered courses, complaints,
     and the assigned department part advisor's email and staff ID.
  4. Submit complaints only for registered courses.

C. Part-advisor review
  1. Open /staff/login and enter a seeded advisor email, staff ID, and password.
  2. Review individual complaints or department-scoped course issue groups.
  3. Resolve, reject with an academic reason, or request more information.
  4. Students receive timeline updates and notifications.

D. Reopened complaint
  1. Sign in as Victor Ekanem and open the CSC 401 script remark complaint.
  2. Review the rejection and the student's justification in the timeline.
  3. The item is returned to UNDER_REVIEW for the same department's part advisor.

--------------------------------------------------------------------------------
3. RESETTING DEMO DATA
--------------------------------------------------------------------------------

Run `npm run seed` only against a disposable database. The seed script drops and
recreates every table and all demo data.

The API initializes the five departments on startup and includes a non-destructive
migration for existing installations. Existing course records are attached to
the original Computer Science with Mathematics department; the admin can change
those memberships in Course Catalog.
